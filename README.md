# Kenko — restaurant website

A historical static website implementation for the Kenko restaurant, built with HTML, CSS and JavaScript.

## Scope

This repository preserves an earlier website version. Other Kenko implementations exist in related repositories; the repository name and deployment configuration have not been changed.

## Local preview

Serve the repository with a local static-file server and open its HTML pages in a browser. For example, with Python installed:

```sh
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/). External embeds, links and media should be checked separately because they may have changed since this version was created.
